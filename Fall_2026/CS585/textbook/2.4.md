## 2.4.1 Services Provided by DNS

- *Domain Name System* (DNS): translates human readable hostnames to IP 
  adresses:
    1. DNS is a distributed database (hierarchy of DNS servers)
        - These servers are UNIX based, running Berkeley Internet Name 
          Domain (BIND) software
    2. Application-layer protocol which allows for database queries
        - Runs over UDP on port 53
- To access a host via domain name:
    1. User runs client side of DNS app
    2. browser gets hostname from the URL and passes it to the client side DNS
    3. DNS client receives a reply (which includes an IP address)
    4. Now browser can initiate a TCP connection
- Some other DNS services:
    - *Host Aliasing*: A more readable alias name rather than displaying the 
      cannonical hostname (EX: www.enterprise.com vs. 
      relay1.west-coast.enterprise.com)
    - *Mail Server Aliasing*: Simplify emails (EX: bob@yahoo.com vs. 
      bob@relay1.west-coast.yahoo.com)
- *Load Distribution*: Busy sites can have a set of IP addresses for multiple 
  servers associated with a single hostname
  
## 2.4.2 Overview of How DNS Works

- `gethostbyname()` is the UNIX function to call in order to translate a 
  hostname to an IP address
- Why is the DNS decentralized:
    - More than one server -> a failure doesn't crash entire internet
    - Handles more traffic
    - Put database 'close to' all querying clients
    - Centralization = more frequent updates for new hosts
    - Decentralized = scalable

### A Distributed, Hierarchical Daatabase

- *Root DNS Servers*: provide IP addresses of TLD servers, 1000 root servers, 
  copies of 13 different databases
- *Top-Level Domain (TLD) Servers*: Each top level domain (com, org, net, edu, gov, 
  uk, fr, ca, jp, etc) has an associated TLD server
- *Authoratative DNS Servers*: every org with a web server/mail server must 
  provide a publicly available DNS that maps host names to IP addresses
- *Local DNS Server*: close to the hosts, ISPs give access to these local 
  DNS servers, which act as a layer of indirection
