# 1.1 What is the Internet?

## 1.1.1 A Nuts-and-Bolts Description
- <u>hosts/end systems</u>: Devices hooked up to the Internet
- <u>Communication links and packet switches</u>: connect end systems together
- Packet switches take a packet coming from an incoming communication link and
  forwards it to an outgoing communication link
    - EX: router, link-layer switches
- <u>route/path</u>: "sequence of communication links and packet switches traversed by
  a packet from the sending end system to the receiving end system"

- Shipping Analogy:
    > "packets are analogous to trucks, communication links are analogous to 
    > highways and roads, packet switches are analogous to intersections, and 
    > end systems are analogous to buildings"
- Protocols:
    - Transmission control Protocol (TCP)
    - Internet Protocol (IP)
- Internet Engineering Task Force (IETF): devlops internet standards
    - Requests for Commments (RFCs): the IETF's standards documentation (~9000
      currently exist)
    - Component standards are developed by other bodies:
        - EX: IEEE 802 LAN Standards Commitee specifies Ethernet and WiFi 
          standards

## 1.1.2 A Services Description

- The internet is "an infrastructure that provides services to applications"
- <u>Distributed applications</u>: applications which involve multiple end systems 
  that exchange data with each other
- "How does one program running on one end system instruct the Internet to 
   deliver data to another program running on another end system?":
    - <u>Socket Interface</u>: "specifies how a program running on one end 
      system asks the Internet infrastructure to deliver data to a specific 
      destination program running on another end system":
        - A rule set
        - Postal Analogy:
            > "the postal service requires that Alice put the letter in an 
            > envelope; write Bob’s full name, address, and zip code in the 
            > center of the envelope; seal the envelope; put a stamp in the 
            > upper-right-hand corner of the envelope; and finally, drop the 
            > envelope into an official postal service mailbox."
        - When you develop an Internet app, you must choose on of the 
          Internet's services (akin to choosing between one of the postal 
          services: express delivery, reception confirmation, etc)
          
## 1.1.3 What Is a Protocol?

### A Human Analogy

> "Implicitly, one then takes a cordial “Hi” response as an indication that 
> one can proceed and ask for the time of day. A different response to the 
> initial “Hi” (such as “Don’t bother me!” or “I don’t speak English,” or some
> unprintable reply) might indicate an unwillingness or inability to 
> communicate."
> "there are specific messages we send, and specific actions we take in 
> response to the received reply messages or other events"

### Network Protocols

- <u>Protocol</u>: "defines the format and the order of messages exchanged 
  between two or more communicating entities, as well as the actions taken on 
  the transmission and/or receipt of a message or other event."
