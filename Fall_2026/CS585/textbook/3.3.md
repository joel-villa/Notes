# 3.3 Connectionless Transport: UDP

## TLDR

- UDP = Faster than TCP
- UDP = data loss, no congestion control
- The Transport Layer header includes: send/recv port #s, length, and checksum
- Checksum: a way of ensuring message data is valid

### 3.3.1 UDP Segment Structure

- Segment:
    - Source port #
    - Dest port #
    - Length: "specifies the number of bytes in the UDP segment (header plus
      data)"
    - Checksum: "to check whether errors have been introduced into the segment"
    - Message
