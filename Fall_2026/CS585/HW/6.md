I picked this quote because it speaks to a flaw in the end-to-end argument 
that the author does not directly address: selfish actors. For example 
consider what would happen if all Internet applications ran UDP with data 
integrity and congestion control being handled in the application layer, 
rather than rellying on the existing TCP protocol (note that this is the 
current trend with more companies switching to QUIC). In such a scenario, it 
is likely that those companies with more name recognition--think the Google's, 
the Meta's, etc.--would be able to dominate resources as their congestion 
protocol would selfishly only apply to thier own applications. This would 
result in a deprevation of resources to those less popular applications and a 
monopolization of resources into those applications that currently hold 
monopolies of other forms. I agree with part of the author's premise, that it 
is sensible to have network layering while keeping performance at front of 
mind. However, this article does not address how to ensure network fairness 
when applications are allowed too much control over networking protocols.
