### Computer Networking:
- 'computer' is outdated -> 'end-system' or 'host' is more sensible
- End System: run 'networking apps', this is known as the edge of the 
  internet
- Two Necessities (other than end system):
    1. Packet switches: abstraction of a role in the system 
        - Examples: routers & switches (link-layer switches)
    2. Communication links: think infrastructure/physical media
        - Examples: fiber, copper, radio, sattelite
        - NOTE: bandwidth is measured in bits/sec
- Example: 
    - End systems: mobile device connected to lobo-wifi
    - Access-point: runs ethernet to a router, then switch (in a server room)
- Types of Networks:
    - Home Network: local    
    - Mobile Network: moving arround (phone)   
    - Enterprise Network (UNM)
